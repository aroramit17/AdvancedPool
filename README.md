# Advanced Pool & Spa LLC Website

Modern static website rebuild for Advanced Pool & Spa LLC, a family-owned North Texas pool service, maintenance, and repair company.

## Files

- `index.html` - homepage, SEO metadata, LocalBusiness schema, service content, quote form
- `styles.css` - responsive visual system, layout, animations, and mobile call CTA
- `script.js` - sticky header, mobile nav, reveal animations, FAQ behavior, and quote form mailto fallback
